About upscaling & clarity. The Upscale tab runs a local pixel pipeline — denoise, then high-quality resampling (Lanczos or smooth), then local-contrast "clarity", then unsharp masking with adjustable radius. It enlarges and sharpens cleanly without uploading anything, but it doesn't hallucinate new detail the way a trained neural super-resolution model would. A browser ML model could slot in as the resampling step if you want learned detail later.
About video. Video conversion and editing run fully in your browser via FFmpeg compiled to WebAssembly (~31 MB, fetched on first use). You can change format (MP4/WebM/GIF), quality, resolution, frame rate, trim, crop to an aspect ratio, and strip audio. Because the browser must spawn a worker, the page needs to be served over http(s) — any static host works, no special headers — and it won't run from a bare file:// double-click. Large/long clips are limited by browser memory.
On watermark removal. I left that feature out on purpose. Tools to strip watermarks — especially AI provenance marks like Google Gemini's SynthID — are mainly used to pass AI images off as authentic or to remove attribution from someone else's copyrighted work, so I'm not comfortable building it. Everything else you asked for is here and fully working.
Metadata is stripped automatically. Every image is decoded and re-encoded locally, so exports come out free of EXIF — including GPS location, camera model, and timestamps. Cards flag when a source file contained location data so you know what was removed.
